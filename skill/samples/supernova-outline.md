## 四、破格判断

**① 眼睛跑得快吗？** 快。首屏内容少、留白大，视线从主张直接滑到底部。

**② 主体够重吗？** 主体是一句话，重量中等偏轻。

**③ 停还是走？** 停。在主张之后摁住一下，再交给下面的数据。

→ 结论：加**承重型**图案。

| 项 | 内容 |
|---|---|
| 图案 | 实心圆，外缘渐变融入背景（非插画，非素材） |
| 位置 | 右侧留白，第 5–6 块 |
| 尺度 | 留白约 1/3，最大 232px，离文字 ≥24px |
| 动效 | 640ms 淡入 + 微缩放（承重型上限） |
| 交互 | 无 |

**为什么不用引导型**：这一屏后面紧跟数据条，视线本来就会往下走，不需要再送。

## 六、这一版踩的坑

1. **渐变的实心区太小（34%）** → 圆看着像一团模糊，不像有重量的形。改成 68% 实心，只留最外一圈淡出。
2. **`.stats__grid { display: contents }`** 把 grid 容器拆了，数字直接堆到页面最左边。删掉这条，让 `.split` 自己当容器。
3. **`min-height: 100vh`** 让首屏在长截图里撑满整屏，后面内容被推到画外。加了 `?flat=1` 参数把首屏压到 640px，专门用于全页截图。
4. **圆里那道白色斜线** 本来想打散实心，实际看起来像划痕。删了。
