# SupernovaAI 站点 · 大纲留档

按 `outline-template.md` 做的四页站点实例。目的是留一份「这样想 → 这样做」的证据。

---

## 站点级

| 项 | 内容 |
|---|---|
| 站点 | SupernovaAI · 推理 API |
| 站点主张 | 把推理延迟压到感知不到 |
| 读者 | 正在选 API 的后端工程师 |
| 页面数 | 4（首页 / 产品 / 定价 / 文档） |

**站点只有一个主张，每页是它的一个侧面。**

| 页 | 这一页的主体 | 破格方式 |
|---|---|---|
| `supernova-site.html` | 把延迟压到感知不到 | **承重**：实心圆，落右侧留白 |
| `site-product.html` | 一个请求怎么走完 | **引导**：一条竖线贯穿三段，从顶部长出来 |
| `site-pricing.html` | 按 token 计费，没有最低消费 | **无破格**（信息密度中等，比例条是数据不是图案） |
| `site-docs.html` | 两行代码换掉 SDK | **无破格**（信息密集，本身就在减速） |

四页共用：6 块地基、版心 1120、栏距 24、第 2 块起、右侧留白留给图案。

---

## 首页

**主体**：那句主张。产品名是标签，占第 1–2 块。

| 元素 | 跨度 |
|---|---|
| 品类标签 | 2 → 4 |
| 主张 | 2 → 6 |
| 支撑文案 | 2 → 5 |
| 按钮组 | 2 → 4 |
| 承重圆 | 右侧留白，绝对定位，不参与文字排版 |

**破格**：承重型，实心圆，留白 1/3，最大 204px，640ms 淡入 + 微缩放，无交互。

**为什么承重不用引导**：首屏后面紧跟数据条，视线本来就会往下走，不需要再送。

---

## 产品页

**主体**：三段流程这条时间线。

**破格**：引导型，一条竖线。竖线是 `.flow__body` 的 `::before`，`scaleY(0) → 1`，900ms，进视口才长出来。点坐在线上，每点对应一段。三段各占 2 → 7 块。

**为什么是引导**：这一页的阅读动作就是「往下走一遍流程」，线负责把视线送下去。

---

## 定价页

**主体**：那句话 + 三档卡。

**无破格**：信息密度中等偏上，三档卡本身提供了结构。比例条（28px 高，免费 6% / 付费 94%）是数据可视化，不是破格图案——它没有接管视线，只是解释数字。

**如果我硬加一处图案**，会和三档卡抢注意力，违反「一屏一个主体」。

---

## 文档页

**主体**：接入这件事本身。

**无破格**：整页都是代码块和参数表，信息密集，本身就在减速。再加图案只会让人找不到重点。

节奏靠标题下的细分隔线维持：`h2` 带 `border-bottom`，每段之间 56px，段内 14px。

---

## 这一版踩的坑

1. **`.actions` 没写 `grid-column`** → 被自动排到右边，压住承重圆。共享样式里 `.actions` 只定义了 `display:flex`，忘了占块。
2. **`.flow__rail` 用计算值定位** → 线在 457、点在 525，错开 68px，线还悬在空白里。改成让 `.flow__body` 自己带 `border`，用 `::before` 做动画，点用 `left: -36px` 坐在线上。
3. **`.stats__grid { display: contents }`** → 把 grid 容器拆了，数字堆到页面最左边。
4. **`.docs__grid { row-gap: 64px }`** → 标题和代码块被拉散。改成 `row-gap: 0`，靠元素 margin 控制节奏。
5. **定价页的比例条做成 96px 高、满宽黑带** → 读起来像进度条，也不是图案。改成 28px 细条。
