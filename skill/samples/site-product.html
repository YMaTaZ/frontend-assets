How it works

一个请求，
走完三段

接入、路由、返回。每段都有明确的耗时预算，加起来就是首 token 的 87ms。

01

接入

把 baseURL 指向我们，其余不变。SDK 兼容 OpenAI 接口，已有的 function calling、JSON mode 都不用改。

预算 0ms · 编译期完成

02

路由

请求落到最近的推理节点。模型权重常驻显存，没有冷启动，所以第一颗 token 不用等加载。

预算 41ms · 含排队

03

返回

流式吐出，首颗 token 先到，后面按生成速度跟。结构化返回在流里保持合法 JSON，不用等结束再解析。

预算 46ms · 首 token

三段预算是示例，真实数值随模型与区域浮动。
