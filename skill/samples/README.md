# samples · 历史样本

**这里的文件是历史样本，不是范例。** 它们产出于规则成型之前，按现在的 `RULES.md` 看有多处不合格，保留是为了留痕与对照，不要照着抄。

写于 2026-11-02，当时规则只有 12 节、没有四道门禁、没有验收表。

## 与当前规则不符的地方

| 问题 | 当前规则 | 本目录的做法 |
|---|---|---|
| 标题上方的小字 | eyebrow 是硬禁，标题自己承担重量（RULES 10 节） | 五页全部有 `.eyebrow` |
| 字体来源 | 本地零文件 / 网页只准 OFL，两套栈不许混（RULES 6.1） | 部分页 `data-fonts="web"` 却写了本地字体名 |
| 动效下限 | 位移 ≥8px、透明度跨 ≥0.3、时延 400–800ms、触发点在视口中部之后（RULES 7.4） | 未按该下限校准 |
| 验证要求 | 每条规则要能验（RULES 1.6） | 当时的截图只看了版式，没量对比度与间距 |
| 圆角 | 外层 12–16 / 内层 8–12 / 控件 6（RULES 6.5） | 部分页统一用一个值 |

## 这五页还有用的部分

不是全无价值。以下是它们仍然成立的贡献：

- `site.css` 的 `.split` 六块地基写法（`repeat(6,1fr)` + `column-gap:24px`），后来被 `slide.css` 继承
- `supernova-site.html` 的承重圆：尺度取留白 2/5、贴边裁掉一部分、不做交互
- `site-product.html` 的引导竖线：细线把视线从标题送到下一块
- `mass-scale.html` 把承重圆的三种尺度并排放，用来目测「过大 / 刚好 / 过小」
- `supernova-outline.md` 的五条踩坑记录

要看的是这几处手法，不是它们的字号、颜色和标签写法。
