Quickstart

两行代码，
换掉现有 SDK

兼容 OpenAI 的接口形状。改一个 baseURL，其余不用动。

安装 鉴权 流式 限制

安装

npm i openai

改一行地址

// 原来
const client = new OpenAI({ apiKey: process.env.KEY });

// 换成
const client = new OpenAI({
  apiKey: process.env.NOVA_KEY,
  baseURL: "https://api.supernova.ai/v1"
});

鉴权

走 Authorization 头，Bearer 形式。key 在控制台创建，可设过期时间与额度上限。

Authorization: Bearer $NOVA_KEY

流式返回

默认流式。每块是合法 JSON，结构化的内容不会在流中途断裂。

const stream = await client.chat.completions.create({
  model: "nova-1",
  stream: true,
  messages: [{ role: "user", content: "你好" }]
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? "");
}

限制

单请求
上下文 128k token，输出上限 8k
并发
免费 2，按量 64，企业可谈
速率
按量默认 600 请求 / 分钟
日志
免费保留 7 天，按量 30 天
超时
流式连接 60s，非流式 30s

以上参数为示例，真实限制以官方文档为准。
