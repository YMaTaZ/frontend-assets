# slide 模式 · 实现规范

`page` 是流式网页，`slide` 是固定画布。两种模式共用同一套 token、同一套等分、同一套字体，差别只在画布与动效触发。

**文件**：`slide.css`（运行层）＋ `slide.js`（翻页与缩放）＋ `slide-template.html`（可直接改的五页样例）。

---

## 一、画布

| 项 | 值 |
|---|---|
| 画布 | **1280 × 720**，16:9，固定不随视口变 |
| 安全边距 | **64px**（内容间距的 3 倍以上） |
| 缩放 | `transform: scale()` 等比缩到视口，`transform-origin: center` |
| 溢出 | **必须一屏装下**。装不下就删内容或换档，不许滚动 |

缩放只改 `transform`，不改宽高。改尺寸会触发重排，翻页时会掉帧。

## 二、字号

幻灯片基准是网页的 **×1.4**。落到实际像素：

| 角色 | 字号 | 用在哪 |
|---|---|---|
| h1（封面 / 章节页） | 64–72px | A 档、C 档 |
| h2（内容页标题） | 40px | B 档 |
| h3（小标题） | 20–24px | 栏内标题 |
| 正文 | 22px，行高 1.75 | 一屏最多 5 行 |
| 元信息 | 14–15px，等宽 | 页码、来源、演示声明 |

**一屏只用一个档位**：封面 A、章节页 C、内容页 B。不许在同一页混。

## 三、翻页

| 操作 | 键 |
|---|---|
| 下一页 | `→` `↓` `Space` `PageDown` ／ 滚轮下 ／ 左滑 |
| 上一页 | `←` `↑` `PageUp` ／ 滚轮上 ／ 右滑 |
| 首 / 末 | `Home` / `End` |
| 全屏 | `F` |

- 地址栏带 `#3` 直达第 3 页，刷新不丢位置
- 进度条 2px，底部贯通；页码用 `tabular-nums`
- 滚轮有 450ms 节流，一格不会翻三页

## 四、动效

**只在一页进入时播一次**，不给滚动触发——`page` 模式那套 `FadeContent` / `ScrollReveal` / `ScrollVelocity` 在幻灯片里根本不触发，改用翻页驱动。

- 元素加 `class="enter"`，JS 自动按 DOM 顺序编号，错开 **90ms**，封顶 6 个
- 幅度按 `RULES.md` 7.4：位移 12px、时长 560ms、透明度 0→1
- 默认态可见，脚本挂了不白屏
- `prefers-reduced-motion` 只减位移，保留淡入

**一页一个焦点时刻**。五页各有一次入场，不等于一页里堆五次入场——同一页内 `enter` 属于同一个序列。

## 五、导出 PDF

已经写好，不用另配：

```css
@page { size: 1280px 720px; margin: 0; }

@media print {
  .slide { display: flex !important; break-after: page; }
  .enter { opacity: 1 !important; transform: none !important; }
}
```

Chrome 里打印 → 目标「另存为 PDF」→ 边距「无」→ 勾掉「页眉页脚」。出来的每页正好 1280×720，一页一张幻灯片。

**坑**：如果打印预览出现空白页，检查最后一页的 `break-after`，模板已用 `:last-child` 处理。背景色打印不出来，是因为没在打印对话框勾「背景图形」。

## 六、与 page 模式的差别

| | `page` | `slide` |
|---|---|---|
| 画布 | 流式 | 1280×720 固定 |
| 动效触发 | 滚动进入视口 | 翻页时入场 |
| 溢出 | 页面变长 | 必须装下 |
| 导航 | 滚动 + 锚点 | 键盘 + 翻页 + 进度 |
| 破格 | 可随滚动出现 | 每页最多一处，且只在该页 |
| 导出 | 不需要 | `@page` 横向打印 |

## 七、不许做的

- 幻灯片里用滚动触发组件（`FadeContent` `ScrollReveal` `ScrollFloat` `ScrollVelocity`）
- 用 `vh` / `vw` 排版面尺寸——画布是固定的，用 px
- 把网页整页塞进来靠缩放硬装（字号会小到不可读）
- 一页两处破格
- 动效用了超过两种材质
- 四角都有装饰、页页都有动画
