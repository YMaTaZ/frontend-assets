# 大纲与主张模板

动笔之前填完。**填不完不许开始设计。**

顺序不能换：**① 两条轴 → ② 大纲（门禁一）→ ③ 动效主张（门禁二）→ ④ 等分 → ⑤ 空间主张（门禁三）→ ⑥ 跨度 → ⑦ 破格（门禁四）→ ⑧ 开工前自查**

---

## ① 两条轴

**交付形态**（选一个）

- [ ] `page` 流式网页
- [ ] `slide` 幻灯片（1280×720，一屏装下，见 `slide.md`）

**访客模式**（选一个，按页面算不按产品算）

| 模式 | 访客的目标 | 例子 | 动效权重 | 破格 |
|---|---|---|---|---|
| [ ] Persuade 说服 | 决定并行动 | 落地页、定价页 | 3–4 | 可有一处承重 |
| [ ] Operate 操作 | 完成一个任务 | 工具界面、设置 | 1–2 | 不加 |
| [ ] Read 阅读 | 看懂一件事 | 文档、说明页 | 1–2 | 不加 |
| [ ] Experience 体验 | 进入作品本身 | 作品集、展示页 | 3–4 | 可有一处，服务主体 |

> 判据：这个页面上，访客「成功了」是什么样子？选不出来就是还没想清。

## ③ 动效主张（门禁二）

四行，与大纲同步写完。**没有一行依赖块数。**

| 行 | 写什么 |
|---|---|
| **焦点时刻** | 整页唯一值得被记住的那个动作序列，一句话说清从什么到什么：____________ |
| **连续性** | 哪些跳转 / 布局变化要解释，用什么（共享元素 / FLIP / 视图过渡）；无则写「无」：____________ |
| **反馈** | 哪些控件与结果要确认，多快（100–150ms）；无则写「无」：____________ |
| **预算** | 哪个效果贵、多久跑一次、哪里降级：____________ |

**门禁二**：写「有个淡入」不算。焦点时刻必须来自这个产品与这个版面。

> 通用淡入上浮、hover 上浮、视差层、逐屏滚动揭示，都不是主张，是默认动作。

## ④ 等分

先切成 N 块，**只一种，不许混**：

| 这一屏的内容量 | 等分 |
|---|---|
| 一件事（hero、章节页） | 6 块 |
| 图文并置、卡片组 | 8 块 |
| 复杂对比、多列并置 | 12 块 |

- 版心：780（阅读）/ 1120（展示）
- 栏距：24

## ⑤ 空间主张（门禁三）

等分之后才写得出「占第几块到第几块」。

- **主次**：哪一块是主体，靠什么尺度与位置压住其他块：____________
- **节奏**：疏与密各落在哪，哪一处是这页的呼吸点：____________
- **落位**：主体占第 ___ 块到第 ___ 块，其余块如何借势：____________

**门禁三**：三行有一行答不出来，不许进入跨度分配。凭手感摆完再补理由，等于没有主张。

| 副标题 | | |

> 上表是常用起止点，不是模板。同一页的不同区块可以换起点：一个靠左、下一个靠右。

## ⑦ 破格（门禁四）

**前提**：全页只有一个主体，破格图案只服务它。

**① 这一屏的眼睛跑得快吗？**

- [ ] 跑得快（内容稀疏、单一主张、大片留白）
- [ ] 跑得慢（信息密集，本身在减速）→ **不加**

**② 主体够重吗？**

- [ ] 主体重 → 加**引导型**（细线 / 箭头 / 序列 / 编号），把视线送出去
- [ ] 主体轻 → 加**承重型**（实心块 / 实心圆 / 色斑），把视线摁住

**③ 加完之后**

- [ ] 视线停在这儿
- [ ] 视线被送到下一块

答不上来 → 不加。

如果加，写出：

| 项 | 内容 |
|---|---|
| 图案是什么 | |
| 承重还是引导 | |
| 它把视线停在哪 / 送到哪 | |
| 动效强度（承重 100–150ms / 引导 150–500ms） | |

**约束**：一屏最多一处（上限不是配额）；图案属于内容层，只能实色，不许玻璃与模糊；只乱它一个，其余全部落在块线上。

## ⑨ 开工前自查

### 浏览器表面（动笔时就要写进去，不是事后补）

- [ ] 文字选区 `::selection` 用主色低饱和版
- [ ] `caret-color` 跟随主色
- [ ] 滚动条细、无轨道底色
- [ ] `:focus-visible` 有，且用主色，不许 `outline: none`
- [ ] 下划线偏移 ≥2px
- [ ] 表格与统计数字 `tabular-nums`
- [ ] 禁用态降不透明度，不换灰字

### 动效（对照 `RULES.md` 7.4）

- [ ] 位移 ≥8px，或透明度跨 ≥0.3，或面积变化 ≥4%
- [ ] 时长 400–800ms
- [ ] 触发点在元素进入视口中部之后，不在加载时点火
- [ ] 一个序列只播一次
- [ ] 作用对象不小于三行文字的高度

### 结构

- [ ] 每个元素都能报出「占第几块到第几块」
- [ ] 起止点全部落在分界线上，没有 2.5 块这种值
- [ ] 同类元素的跨度一致
- [ ] 破格最多一处，且答得出「停在哪 / 送到哪」
- [ ] 除了图案，其余元素都在块线上
- [ ] 楷体不超过一段
