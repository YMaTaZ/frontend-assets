# 大纲模板

动笔之前填这张表。**填不完不许开始设计。**

---

## 一、这一屏要说什么

| 项 | 内容 |
|---|---|
| 页面 / 区块名 | |
| 一句话主张 | |
| 读者是谁 | |

## 二、内容分块

按视觉顺序，从上到下。每块三行：主张 / 支撑 / 素材。

| # | 优先级 | 主张（一句话） | 支撑（1–3 条） | 素材类型 | 占几列 |
|---|---|---|---|---|---|
| 1 | 主 | | | 文字 / 图 / 数据 / 代码 | |
| 2 | 次 | | | | |
| 3 | 辅 | | | | |

**优先级规则**：一屏只能有一个「主」。两个主 = 没有主。

## 三、网格选型

| 这一屏的内容形状 | 选 |
|---|---|
| 单一主张（hero、章节页） | 6 列 |
| 图文并置、卡片组、多列对比 | 12 列 |
| 极短、居中、对称内容 | 4 列 |

- 版心：780（阅读）/ 1120（展示）
- 栏距：24
- 基线：28（正文 16 × 行高 1.75）

## 四、破格判断

逐条问，满足其一才允许破格：

- [ ] 需要一个视觉主角（一个数字 / 一句主张 / 一张图）
- [ ] 需要打破等距节奏制造呼吸
- [ ] 需要区分章节或状态
- [ ] 素材本身比文字宽（大图、时间轴、地图）

如果勾不了任何一条 → **不破格，全部落在网格内。**

如果勾了，写出：

| 项 | 内容 |
|---|---|
| 破格元素是什么 | |
| 它在强调什么 | |
| 手法（出血 / 跨列 / 超大字号 / 溢出 / 旋转） | |
| 下一屏怎么「立」回来 | |

## 五、字体角色

| 角色 | 用在哪 | 字重 |
|---|---|---|
| body | | 400 |
| display | | 500 / 600 |
| kai（可选，一页最多一处） | | 400 |
| mono | | 400 |

## 六、完成检查

- [ ] 每个元素都能报出「占第几列到第几列」
- [ ] 段落宽度是列宽整数组合，没有脱离网格的值
- [ ] 破格不超过一处，且能回答「在强调什么」
- [ ] 破格后下一屏回到了网格内
- [ ] 楷体不超过一段
- [ ] 按 `g` 打开网格叠加层，肉眼确认没有歪
