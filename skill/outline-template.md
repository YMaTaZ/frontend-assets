## 二、内容分块

按视觉顺序，从上到下。每块三行：主张 / 支撑 / 素材。

| # | 优先级 | 主张（一句话） | 支撑（1–3 条） | 素材类型 | 占哪几块 |
|---|---|---|---|---|---|
| 1 | 主 | | | 文字 / 图 / 数据 / 代码 | |
| 2 | 次 | | | | |
| 3 | 辅 | | | | |

**优先级规则**：一屏只能有一个「主」。两个主 = 没有主。

## 三、等分与跨度

先把界面等分成 N 块（只一种，不许混）：

| 这一屏的内容量 | 等分 |
|---|---|
| 一件事（hero、章节页） | 6 块 |
| 图文并置、卡片组 | 8 块 |
| 复杂对比、多列并置 | 12 块 |

- 版心：780（阅读）/ 1120（展示）
- 栏距：24

再逐个元素写跨度。**起点自由**，只要落在分界线上：

| 元素 | 第 a 块 → b 块 | 备注 |
|---|---|---|
| logo | | 通常第 1 块 |
| 导航 | | 可靠右 |
| 主标题 | | 可以不从第 1 块起 |
| 副标题 | | |
| 正文 | | |
| 按钮组 | | |
| 元信息 | | |

> 上表是常用起止点，不是模板。同一页的不同区块可以换起点：一个靠左、下一个靠右。
> 规整感来自反复落在同一批位置上，不来自规定谁站哪。

## 四、破格判断

**前提**：全页只有一个主体，破格图案只服务它。

按顺序问：

**① 这一屏的眼睛跑得快吗？**

- [ ] 跑得快（内容稀疏、单一主张、大片留白）
- [ ] 跑得慢（信息密集，本身就在减速）→ **不加**

**② 主体够重吗？**

- [ ] 主体重 → 加**引导型**（细线 / 箭头 / 序列 / 编号），把视线送出去
- [ ] 主体轻 → 加**承重型**（实心块 / 实心圆 / 色斑），把视线摁住

**③ 加完之后**

- [ ] 视线停在这儿
- [ ] 视线被送到下一块

答不上来 → 不加。

如果加，写出：

| 项 | 内容 |
|---|---|
| 图案是什么 | |
| 承重还是引导 | |
| 它把视线停在哪 / 送到哪 | |
| 动效强度（承重 100–150ms / 引导 150–500ms） | |

**约束**：一屏最多一处（上限不是配额）；图案属于内容层，只能实色，不许玻璃与模糊；只乱它一个，其余全部落在块线上。

## 六、完成检查

- [ ] 每个元素都能报出「占第几块到第几块」
- [ ] 起止点全部落在分界线上，没有 2.5 块这种值
- [ ] 同类元素的跨度一致
- [ ] 破格最多一处，且能回答「把视线停在哪 / 送到哪」
- [ ] 破格图案是实色，没有玻璃或模糊
- [ ] 除了图案，其余元素都在块线上
- [ ] 楷体不超过一段
