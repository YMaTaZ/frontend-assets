# 排版 · 三档体系

极简风格的排版不是「字号少」，是「层级清楚且克制」。三档不是三选一，是三种信息密度，按内容类型调用。

配套文件：`tokens.css`（可直接引用）　`typography.html`（三档对照页）

---

## 1. 共用刻度

三档都从同一批值上取点，不会出现 1.4rem 这种野生数字。

| rem | px | 用途 |
|---|---|---|
| 0.8125 | 13 | 元信息，全站固定 |
| 0.875 | 14 | 小字 |
| 1 | 16 | 正文底线 |
| 1.125 | 18 | 过渡 |
| 1.25 | 20 | h2 / h3 |
| 1.5 | 24 | h2（B 档） |
| 1.75 | 28 | h1 |
| 2.125 | 34 | 展示级 |

---

## 2. 三档定义

### A · 精简三档

```
1.75 / 1.25 / 1.0        →  28 / 20 / 16
```

- **用在**：落地页、单一信息页、幻灯片封面
- **特点**：一屏一个主张，没有中间层。最大的是主张，其余都是解释
- **代价**：长文档难分层
- **行高**：标题 1.2 / 正文 1.75

### B · 四档带过渡（默认）

```
1.75 / 1.5 / 1.25 / 1.0  →  28 / 24 / 20 / 16
```

- **用在**：项目详情、作品集内页、长文档、幻灯片内容页
- **特点**：补上 20px 这一层，让「组」和「段」之间有了落差
- **行高**：标题 1.25 / 正文 1.75

### C · 苹果式双档

```
2.125 / 1.0625           →  34 / 17
```

- **用在**：幻灯片章节页、数据大字、全屏主张
- **特点**：极端对比，中间不设过渡，层级靠尺度差与留白
- **实现**：h2 / h3 退化为与 h1 同字号，用 0.72 透明度区分
- **行高**：标题 1.1 / 正文 1.7

---

## 3. 使用规则

1. **一屏只用一套**。不许 A 的标题配 B 的正文
2. **小字固定** 0.8125rem（13px），不参与档位变化
3. **字重只用 400 / 500**；600 仅限 ≥2.125rem 的展示字（C 档 h1）
4. **不用 Inter 当默认脸**
5. **C 档正文用 17px**（苹果正文基准），不用 16

### 幻灯片的分派

| 页型 | 档位 |
|---|---|
| 封面 | A |
| 章节页 | C |
| 内容页 | B（默认） |

---

## 4. 阅读度量

- 行宽上限 `--measure: 32em`
  - 中文 ≈ 32 字/行
  - 英文 ≈ 64 字符/行
- 超过 38 个中文字会跳行
- 图注、引言可用 `--measure-wide: 40em`
- 行高随行宽反向调，不给固定比值

---

## 5. 中英混排

- 中文：`system-ui, "PingFang SC", "Microsoft YaHei", sans-serif`
- 英文：同栈，靠 `system-ui` 落到各平台默认
- 数字、代码：等宽（`--font-mono`），开 `tnum` 数字等宽
- 中英混排时英文不额外加字号，靠字符自身宽度自然区分

---

## 6. 深底浅字

三轴补偿，缺一件就会显得发虚：

| 轴 | 调整 |
|---|---|
| 行高 | 1.75 → 1.8 |
| 字距 | +0.012em |
| 字重 | 400 → 450 |

---

## 7. 怎么用

```html
<link rel="stylesheet" href="tokens.css">

<html data-ramp="b">          <!-- a / b / c -->
```

所有字号走 CSS 变量，正文里不写死 px：

```css
h1 { font-size: var(--h1); line-height: var(--lh-title); }
p  { font-size: var(--body); line-height: var(--lh-body); max-width: var(--measure); }
```

切档只改 `data-ramp` 一个字母。

---

## 8. 检查清单

- [ ] 一屏只用了一套档位
- [ ] h1 / h2 / h3 之间至少差 1 个刻度（C 档除外，它故意不分层）
- [ ] 正文没小于 16px（C 档 17px）
- [ ] 中文单行不超过 38 字
- [ ] 没有 600 以上的字重，除 C 档 h1
- [ ] 元信息统一 13px
- [ ] 深底页做了三轴补偿
- [ ] 打印/导出时字没被压小

## 9. 待调项

以下数值是首版建议，看到实际效果后可改：

| 项 | 当前 | 说明 |
|---|---|---|
| C 档正文 | 17px | 若觉得偏大改 16 |
| 行宽上限 | 32em | 若觉得窄改 34em（≈34 中文字） |
| A 档 h2 | 20px | 若觉得跳跃感太强改 18px |
