# 图标

图标是控件层的零件，不是内容。它要小、要准、要不抢戏。

---

## 一、尺寸只有三档

| 尺寸 | 用在哪 | 笔画 |
|---|---|---|
| **16px** | 行内、按钮内、表格里 | 1.5px |
| **20px** | 导航、工具条、输入框前缀 | 1.5px |
| **24px** | 空态、卡片头、单独出现的图标 | 1.75px |

**不许出现 18、22、28 这种中间值。** 三档之外就是没做决定。

同一屏里图标尺寸不超过两档。一个 16 一个 24 并排，视觉重量差两倍，看着像两个系统。

## 二、笔画

- 线宽统一 **1.5 或 1.75**，一屏只能用一种
- 直角圆角 `rx = 1`（16px 图上）到 `rx = 2`（24px 图上），跟画面的同心圆角走
- 端点 `stroke-linecap="round"`，但**只在一套内统一**，不要混圆头和方头
- 填充图标与线性图标**不混用**。要么全线性，要么实心只在「选中态」出现

## 三、光学对齐

图标看起来对齐，靠的不是数学居中。

- 图标与文字并排时，**按视觉重心对齐**，通常要下移 1px
- 图标的「外框」不等于它的视觉边界：圆形的视觉中心比几何中心高一点，需要补偿
- 与文字搭配时，图标宽度取**字号 × 1.25** 左右（16px 字配 20px 图标），不要与字高齐平

## 四、颜色

- 默认跟随**当前文字色**（`currentColor`），不自带色值
- 只有「强调」「激活」两种状态可以上主色
- 禁用态跟文字一起降不透明度，不单独换灰

## 五、来源

**只允许两种：**

1. **现成图标库**（Lucide、Feather、Phosphor 等线性库），且**只用一套**
2. **自己画的 SVG**，坐标自己写得出来

**禁止：**

- emoji 或 Unicode 符号冒充图标（🎉 ✓ ★ → 这种）
- 两套库混用（Lucide 的箭头 + Feather 的齿轮，线宽对不上）
- 位图图标（PNG / 带阴影的 JPG 小图）
- 带渐变、带阴影、带描边的装饰性图标

## 六、可访问性

- 纯装饰图标：`aria-hidden="true"`
- 图标按钮：必须有 `aria-label`，且 `title` 可选
- 触控目标 ≥44×44：图标本身 16px 时，靠 `padding` 撑到 44
- 图标 + 文字按钮里，图标不重复文字的语义，别让读屏念两遍

## 七、检查

- [ ] 一屏不超过两档尺寸
- [ ] 笔画宽度全页一种
- [ ] 没有 emoji 冒充图标
- [ ] 没有两套库混用
- [ ] 线性与填充没有混用
- [ ] 图标按钮有 `aria-label`
- [ ] 16px 图标配够 44px 触控区
