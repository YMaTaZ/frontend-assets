# 极简设计风格 · 规则

个人前端设计规范。用于生成网页与 HTML 格式的 PPT。
这份文件是决策记录与规则真源，`SKILL.md` 由它派生。

## 1. 两种模式 【定】

同一套 token，两种驱动方式。

| | `page` 网页 | `slide` 幻灯片 |
|---|---|---|
| 画布 | 流式，随视口伸缩 | 固定 1280×720，等比缩放 |
| 动效触发 | 滚动进入视口 | 翻页时入场 |
| 字号基准 | 16px | ×1.4 倍率 【默认】 |
| 导航 | 滚动 + 锚点 | ← → 翻页、键盘、进度 |
| 溢出 | 页面变长 | 必须一屏装下 |
| 导出 | 不需要 | 打印成 PDF，`@page` 横向 |

**硬约束**：`slide` 模式禁用一切滚动触发组件。`FadeContent`、`ScrollReveal`、`ScrollFloat`、`ScrollVelocity` 在幻灯片里不会触发，改用翻页驱动的入场。

## 2. 配色

### 2.1 纲领 【定】

**不锁色值，锁原则。** 风格标签（木色极简、意式极简）只定气质，不预设 hex。

色值来自独立仓库 `frontend-assets`，技能只引用，不内置。

### 2.2 五条硬规则 【定】

1. 单画面 **≤5 色**
2. 每个画面有**一个明确主色**（主色可以是中性色本身）
3. 对比**克制**，不出现高对比
4. **留白充足**
5. 用亮色时总色数 **≤3**，且亮色只承担三种职能之一：强调功能 / 突出主体 / 凸显个性

### 2.3 多色的唯一合法理由 【定】

同系列不同产品之间做区分。除此之外，多色就是失控。

### 2.4 底子 【参考，不强制】

三组方向，从库里挑，不钉死：

| 方向 | 库里对应 |
|---|---|
| 灰系中性（暖灰 / 冷灰 / 石灰色 / 灰褐） | `stone` `neutral` `zinc` `gray` `slate` |
| 米色与大地（米白 / 燕麦 / 沙色 / 浅咖 / 灰褐） | `ivory` `oat` `sand` `clay` `taupe` |
| 黑白灰 | `neutral` 的两端 |

### 2.5 可测阈值 【默认】

形容词落不了地，补两个数：

- 中性色饱和度：HSL 里 **S ≤ 45%**
- 主色与底色的明度差（Lab ΔL）：**20–35** 之间；超过 50 算高对比，不合规

浏览页里点两个色块就能算出 ΔL 和对比度，超了会标红。

### 2.6 亮色 【定】

- 只用于强调、主体、个性三件事之一
- 单画面最多 1 个亮色色相，最多用它的 2 个档
- 大面积色块不得用亮色，亮色面积建议 ≤8% 画面

## 3. 字体与字号

### 3.1 字族 【定】

- 中文：`system-ui, "PingFang SC", "Microsoft YaHei", sans-serif`
- 英文：`system-ui, -apple-system, "Segoe UI", sans-serif`
- 不用 Inter 当默认脸（它是 LLM 默认）

### 3.2 字重 【定】

只用 **400 / 500**。层级靠字号、颜色、间距，不靠加粗。

### 3.3 网页字号档 【定】

| 角色 | 尺寸 | 行高 |
|---|---|---|
| 页面标题 | 1.6–1.8rem | 1.25 |
| 区块标题 h2 | 1.2–1.3rem | 1.35 |
| 小标题 h3 | 1.0–1.05rem | 1.45 |
| 正文 | 15–16px | 1.6–1.7 |
| 元信息 | 0.78–0.85rem | 1.5 |

### 3.4 阅读度量 【定】

- 正文 16px 是底线，不再往下
- 行宽 **45–75ch**（中文约 22–38 字）
- 行高随行宽反向调：越宽行高越大，不给固定比值
- 深底浅字做三轴补偿：行高 +、字距 +、字重 +1

### 3.5 幻灯片字号 【默认】

按网页档位整体 **×1.4**。投影可读的底线是正文 ≥22px。

## 4. 间距与网格

### 4.1 阶梯 【定】

**4 为基单位**：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`

纯 8 会缺中间档，4 基能覆盖。

### 4.2 常用值 【定】

| 用途 | 值 |
|---|---|
| 版心 | 780–820px |
| 正文内边距（桌面） | 40–54px |
| 区块间距 | 28–36px |
| 段落间距 | 8–10px |
| 幻灯片安全边距 | 64px 【默认】 |

### 4.3 原则 【定】

- 分组靠**邻近**，不靠加容器和装饰
- 节奏来自 tight 与 generous 的**对比**，不要一个间距值铺满全页
- 数学上对齐，不留歪缝

## 5. 版面

### 5.1 眯眼测试 【定】

虚化细节后，仍能一眼分出**主、次、组**的顺序。分不出就是层级失败。

### 5.2 结构 【定】

- 禁止**三栏等高功能卡**
- 重复的卡片 / 分栏必须真的等价，否则是框架默认
- 响应式是**结构性重排**（重排、折叠、回流），不是等比缩小
- 触控目标可用，即使视觉标记很小

### 5.3 留白率 【默认】

网页 **≥55%**，幻灯片 **≥45%**。

## 6. 动效

### 6.1 时长表 【定】

| 时长 | 用途 |
|---|---|
| 100–150ms | 即时反馈（按下、hover） |
| 150–300ms | 常规状态切换 |
| 300–500ms | 布局、浮层、视图切换 |
| 500–800ms | 焦点入场 |

**出场比入场快。**

### 6.2 缓动 【定】

`cubic-bezier(0.16, 1, 0.3, 1)`
不反射性上 bounce / elastic。

### 6.3 节流 【定】

- **只给一个焦点时刻**，不要每个区块都做滚动揭示
- **同屏同时只让一个东西动** 【默认：1 个序列】
- 入场时多个元素一起动，观感立刻从高级掉到模板

### 6.4 强度 【默认】

`MOTION_INTENSITY = 2/10`。`taste-skill` 的基线是 6，对极简是对冲的，必须覆盖。

### 6.5 技术约束 【定】

- 默认状态内容必须可见，脚本挂了不能白屏
- 不动 `width / height / top / left / margin`，用 transform 或 FLIP
- 模糊、滤镜、阴影、canvas、shader 限制在局部区域
- `will-change` 只在动画期间加
- `prefers-reduced-motion` 要留替代路径：减少位移，保留状态变化，不是全关

## 7. 组件选型

指向 `my-react-components` 的 213 个组件。

### 7.1 能用

| 用途 | 组件 |
|---|---|
| 入场 | `FadeContent` `BlurText` `AnimatedContent` `ScrollReveal` |
| 文字节奏 | `SplitText` |
| 数字 | `CountUp` |
| 光标反馈 | `Magnet` `GlareHover` `SpotlightCard` |
| 导航 | `LineSidebar` |
| 提示 | `WarmTooltip` |
| 循环 | `LogoLoop` `ScrollVelocity` |
| 质感 | `Noise`（2–4% 透明度） |

### 7.2 慎用（一屏最多一个）

`ClickSpark` `CursorGrid` `MagnetLines` `Threads` `Aurora` `GradientBlinds`

### 7.3 禁用

`SplashCursor` `Ballpit` `MetaBalls` `Hyperspeed` `FallingText` `LetterGlitch`

### 7.4 模式限制 【定】

`slide` 模式下，7.1 里凡是滚动触发的（`FadeContent` `ScrollReveal` `ScrollVelocity`）降级为翻页触发或直接不用。

## 8. 反例清单

出现以下任何一条，视为不合格：

- AI 紫渐变、深色 mesh 居中的 hero
- 三张一模一样的功能卡横排
- 玻璃拟态滥用、`backdrop-filter` 到处糊
- 每屏都做滚动揭示、无休止微动效
- Inter + slate-900 组合
- 渐变按钮、重阴影（超过 `rgba(0,0,0,.04)`）
- 纯黑 `#000` / 纯白 `#fff` 大面积使用
- 多个强调色同时出现
- 字重 >500、边框 >2px
- 冷灰文字 `#666` `#888` `#999`
- 假名字（John Doe）、Lucide 用户图标当头像
- 每段都加图标、每个区块都套卡片
