# 验收表 · checklists

来源：`impeccable` 4.8.0 的 `audit.md`、`harden.md`、`adapt.md`、`optimize.md`、`onboard.md`，2026-11-03 吸收。
只收**可测**的项。测不了的写进 `RULES.md` 的取向里，不进这张表。

**用法**：交出去之前四张表各走一遍，一行不对就退回。全部通过才算完工。

---

## A 可访问性

| 查什么 | 标准 |
|---|---|
| 对比度 | 正文与占位 ≥4.5:1；大字（≥24px 或 ≥19px 粗体）≥3:1；AAA 目标 7:1 |
| 键盘 | Tab 顺序合理、焦点环可见、没有键盘陷阱 |
| 语义 | 标题层级连续（一屏一个 h1）、有 landmark、按钮用 `button` 不用 `div` |
| 表单 | 每个输入有 label、错误信息说明问题与出路、必填有标记 |
| 图片 | 有意义的图有 alt；纯装饰的空 alt |
| 触控目标 | ≥44×44px。WCAG 2.5.8 底线 24×24，例外条件是间距、等价控件、行内文字、浏览器默认 |
| 动效 | `prefers-reduced-motion` 必须有意图明确的替代方案：减位移、保留状态变化 |
| 文字缩放 | 200% 不破版、不丢内容、容器跟着扩张 |
| 输入字号 | 移动端输入框 ≥16px（低于 16px 时 iOS Safari 会强制缩放，表单直接崩） |

**反例**：全局 `0.01ms` 一刀切关掉动效。它保住了「不动」，却把「按下去有反馈」也一起杀了。

## B 边界（harden）

| 维度 | 要试的 |
|---|---|
| 超长文本 | 长人名、长标题、长描述是不是破版或被裁 |
| 超短文本 | 空串、单字、单个符号 |
| 特殊字符 | emoji、RTL（阿拉伯/希伯来）、重音符号 |
| 大数字 | 百万、十亿级别的位数 |
| 长列表 | 1000+ 条、50+ 个选项 |
| 无数据 | 空态要说清三件事：这里会有什么 / 为什么重要 / 怎么开始 |
| 断网 | 离线、极慢、超时各自的界面 |
| 接口错误 | 400、401、403、404、500 各有各的文案，不共用一句「出错了」 |
| 校验错误 | 错在哪、怎么改，两件都要说 |
| i18n | 德语常比英文长 30%；RTL 要镜像；日期、数字（1,000 vs 1.000）、货币符号各按地区 |
| 并发 | 重复点击、乐观更新失败怎么回滚 |
| 权限 | 无权查看时的界面不是白屏 |

**判据**：把最长和最空的两组数据塞进去还能看，才算做完。

## C 响应式（adapt）

| 项 | 值 |
|---|---|
| 断点 | 按内容定，不按设备。常用 640 / 768 / 1024，够用的通常三个 |
| 窄端 | 320px 不出现横向滚动 |
| 正文 | 移动端 ≥16px |
| 触控 | 目标 ≥44×44px；触屏禁用只靠 hover 的交互 |
| 流体 | 用 `clamp()` 做连续变化，少加断点 |
| 大屏 | 4K 上版心不无限拉宽，行宽仍在 65–75ch |
| 打印 | 去背景色、保黑字、链接补 URL、交互元素移除 |

## D 性能

| 指标 | 阈值 |
|---|---|
| LCP | <2.5s |
| INP | <200ms |
| CLS | <0.1 |

| 做法 | 要求 |
|---|---|
| 图片 | lazy 加载 + 写明宽高（防 CLS）；不放大图 |
| 动效 | 不动 width / height / top / left / margin；不用 FLIP 以外的布局动画 |
| 重效果 | blur、filter、shadow、canvas、shader 限制在局部，且不常驻 |
| `will-change` | 只在已知动画期间挂上，静止时撤掉 |
| 字体 | woff2 + `font-display: swap`；首屏字重预加载 |
| 依赖 | 现有栈能干净表达的，不加库 |

## E 一页收尾清单

- [ ] 对比度过关，彩色底上没出现灰字
- [ ] 键盘 Tab 一遍，焦点环全程可见
- [ ] 320px 无横滚，200% 缩放不破
- [ ] 最长 / 最空两组数据塞进去还能看
- [ ] 空态、错误态、加载态各有一个真实界面
- [ ] 动效只看得到一个焦点时刻，且拿掉它页面会丢掉一个意思
- [ ] 选区、光标、滚动条、焦点环、表格数字都不是浏览器默认
- [ ] 五秒内答得出「这一页主体是什么」
